# Vision Transformer – Handwritten Digit Recognition

This project uses a **Vision Transformer (ViT)** model to read handwritten digits and convert them into typed numbers.  
It demonstrates the power of transformer-based architectures in computer vision tasks like Optical Character Recognition (OCR).

---

## 📌 Features
- **Vision Transformer Architecture** – Patch embedding + transformer encoders for image classification.
- **Handwritten Digit Recognition** – Trained to recognize digits from 0–9.
- **AI-Powered Conversion** – Outputs recognized digits as typed text.
- **Modular Design** – Easily adaptable to other OCR or image classification tasks.

---

## 🛠️ Tech Stack
- **Language**: Python
- **Frameworks & Libraries**:
  - PyTorch
  - Torchvision
  - NumPy
  - Matplotlib
- **Dataset**: MNIST (or other handwritten digit datasets)
